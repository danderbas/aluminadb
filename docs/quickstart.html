aluminadb — quick start

Two steps, recorded end to end against a real MySQL 8 container: install the schema, then load the anonymized sample data. See the README to run it yourself.

1. Setting up the schema

docker compose up -d, then bash src/bash/do.sh — the real, unfiltered -vv output: every statement in full, tables through procedures, exactly as it runs.

2. Loading the data

bash src/bash/doloaddata.sh — same deal, full -vv output: every CSV loaded through a staging table, with the real per-table staging_check summaries as they're printed.
